# Privacy Policy

Updated: June 12, 2026

This Privacy Policy (hereinafter referred to as Policy) applies to all information about the user that Evercom Service can obtain during Service use of Evercom software package, located on the website [https://evercom.app](https://evercom.app).

Use of the Service means unconditional consent of the User with the current Policy and the terms for processing of his personal information. In case of disagreement with these terms, the user must refrain from using the Service.

## 1. User's Personal Information Received and Processed by Evercom

1.1. For the purposes of this Policy, "User's personal information" includes the following:

1.1.1. Personal information about the User provided by the User directly upon registration (creation of the account) and during Service use, including User's personal data. User's personal data includes full name and email address. Other information is provided by the User at his discretion.

1.1.2. Data that is transferred automatically to the Service during its use through the software installed on the User's device, including the IP address and cookies.

1.2. This Policy applies only to the Evercom Service and does neither control nor accept any responsibility associated with third-party sites to which the User may be redirected using the links available on the Evercom Website, including search results. Other personal information of the User can be collected and requested, and other actions may be performed by the User on these websites.

## 2. Purpose of Collecting and Processing User's Personal and Non-Personal Information

2.1. Evercom collects and stores only personal data necessary for the provision of services (execution of agreements and contracts with the user).

2.2. User's personal information can be used by Evercom for the following purposes:

2.2.1. Identification of the party under agreements and contracts with Evercom;

2.2.2. Providing the User with personalized services;

2.2.3. Communication with the User, including sending notifications, inquiries, and information regarding Service use, provision of services, as well as processing of User's requests;

2.2.4. Improvement of Service quality and ease of use; development of new functions and services;

2.2.5. Creation of posts in various social networks on behalf of the User. Evercom uses data provided by the User for creating posts on social networks.

## 3. Conditions for Processing User's Personal Information and Its Transfer to Third Parties

3.1. The User's personal information is stored confidentially, except for cases of voluntary provision of personal information by the User for general access to an unlimited number of persons.

3.2. Evercom has the right to transfer the User's personal information to third persons in the following cases:

3.2.1. The user has expressed his consent to these actions;

3.2.2. The transfer is necessary as part of the Evercom Service use, namely creation of posts on social networks by the User;

3.2.3. To detect, prevent, and resolve issues related to fraud, security considerations, and technical aspects;

3.2.4. To respond to User's requests;

3.2.5. The transfer is provided by applicable legislation as part of the procedure established by law.

3.3. Storage of personal data:

3.3.1. The User's personal data is stored on secure electronic media and servers and is processed using automated server systems.

3.3.2. The service administration ensures the safety of personal data of users in accordance with modern standards for the protection of personal data and applicable legislation.

3.4. Evercom does not use or transfer personal data of users to work with artificial intelligence.

## 4. Change of User's Personal Information by the User

4.1. The User can change (update, supplement) the personal information provided by him fully or partially any time using the function of personal data editing in the Service section Personal Account.

4.2. The User can also delete the personal information provided by him for a specific account any time by removing his accounts from the service.

This data will only be used by Evercom to provide you with the expected Service and will not be shared with third parties. When using the YouTube API through Evercom, you must comply with the [YouTube Terms of Service](https://www.youtube.com/t/terms). See also information about the [Google Privacy Policy](https://policies.google.com/privacy).
